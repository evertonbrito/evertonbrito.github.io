An orbital workplace

Make orbit
a place to work.

Tessera is Astreia’s modular orbital platform. It is being developed to support research and manufacturing in microgravity, turning time in space into useful work.

The platform and the return vehicle belong to the same mission: Tessera provides the place to work; Thor provides the way back.

02 / OPERATE

Put microgravity to work.

03 / RETURN

Close the loop.

Plan the journey back with Thor so the mission connects to its next step on Earth.
